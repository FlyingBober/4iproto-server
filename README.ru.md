## 🚀 Возможности

### 🔒 Функции безопасности
- **Встроенная защита от брутфорса**: Автоматическая блокировка IP-адресов после серии неудачных попыток входа
- **Мониторинг атак**: Детальное логирование неудачных попыток авторизации с фиксацией IP-адреса
- **Гибкая аутентификация**: Настраиваемое максимальное количество попыток входа
- **Система блокировки IP**: Персистентное хранение черного списка IP в формате JSON
- **Кастомизация баннера сервера**: Возможность скрыть или изменить приветственный баннер сервера через конфигурацию
- **Разграничение уровней доступа**: Два режима работы — Пользователь (`User`) и Администратор (`Administrator`). Администраторы могут выполнять команды в системном шелле ОС, тогда как обычные пользователи могут исключительно поднимать туннели.

### 📊 Мониторинг трафика
- **Отслеживание трафика в реальном времени**: Раздельный учет исходящего (upload) и входящего (download) трафика для каждого пользователя
- **Статистика по сессиям**: Подсчет переданных и принятых байт в рамках каждой отдельной сессии
- **Совокупная аналитика**: Накопительная статистика использования трафика по всем сессиям
- **Автоматическое сохранение данных**: Периодическая фиксация статистики трафика в JSON-файлы каждые 10 секунд при наличии изменений
- **Мониторинг пропускной способности**: Отображение нагрузки на канал в реальном времени
- **Блокировка нежелательных веб-сайтов**: Блокировка доступа пользователей к запрещенным доменам
- **Блокировка нежелательных IP-адресов**: Блокировка доступа пользователей к конкретным IP-адресам
- **Логирование посещенных сайтов**: Возможность логирования веб-ресурсов, запрашиваемых пользователями (включается опционально)

### 🌐 Сетевые возможности
- **Мультипортовый режим**: Одновременная работа сервера на нескольких портах
- **TCP Forwarding**: Прямой проброс TCP-соединений без необходимости дополнительной настройки
- **UDP Forwarding**: Полноценная поддержка проброса UDP-трафика
- **Кроссплатформенность**: Работает на операционных системах Linux и Windows
- **Высокая производительность**: До 10 раз быстрее стандартного OpenSSH при работе с туннелями
- **Поддержка DNSTT**: Продвинутое туннелирование через протокол DNS для маршрутизации трафика в сложных сетевых условиях

### 🛠️ Функции управления
- **Управление пользователями**: Аутентификация и хранение учетных записей в формате JSON
- **Интеграция с шеллом**: Нативная поддержка командной строки (CMD в Windows, Shell в Linux)
- **Управление конфигурацией**: Серверная конфигурация в формате JSON
- **Система логирования**: Комплексное логирование подключений и попыток атак

### 🧾 Аккаунтинг и биллинг
- **Контроль параллельных сессий**: Администратор может задавать лимит одновременных подключений для каждого аккаунта
- **Автоматическое завершение сессий**: У каждой сессии определено время жизни (TTL). Протухшие сессии автоматически завершаются для освобождения ресурсов
- **Динамическая обработка подключений**: При исчерпании лимита сессий новые подключения отклоняются
- **Мониторинг сессий в реальном времени**: Отслеживание и аудит всех активных сессий в режиме реального времени
- **Мгновенная блокировка превышающих лимит соединений**: Если учетная запись превышает установленный лимит сессий, новые попытки подключения блокируются сразу на этапе аутентификации
- **Ограничение скорости (Rate Limiting)**: Настройка максимальной скорости передачи данных (`max_speed_kbps`) в КБ/с для каждого пользователя. Применяется в реальном времени с использованием алгоритма Token Bucket как для upload, так и для download.  
  **📌 Пример**: `1024` = 1 МБ/с

- **Контроль лимита трафика (Traffic Limit Enforcement)**: Ограничение суммарного объема трафика (`max_total_mb`) в МБ. При превышении квоты доступ блокируется при попытке входа, а активная сессия принудительно разрывается.  
  **📌 Пример**: `10240` = 10 ГБ

- **Контроль расхода трафика в реальном времени**: Проверка расхода трафика каждые 1–2 секунды с немедленным завершением сессии при исчерпании квоты

## 🚀 Простая установка через Abdal 4iProto Cli

[**Abdal 4iProto Cli**](https://github.com/ebrasha/abdal-4iproto-cli) — инструмент командной строки для управления экосистемой Abdal 4iProto. Он автоматически определяет операционную систему и архитектуру, проверяет контрольные суммы SHA-256, настраивает порты, генерирует SSH-ключи, регистрирует службы автозапуска (systemd / Windows Service) и позволяет установить графическую панель [**Abdal 4iProto Panel**](https://github.com/ebrasha/abdal-4iproto-panel) для управления пользователями и настройками сервера.

Полное руководство по развертыванию, клиентам и настройке доступно в 📘 **[Официальной документации](https://ebrasha.github.io/abdal-4iproto-server/)**.
