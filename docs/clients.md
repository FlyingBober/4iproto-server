# Настройка клиентов для Abdal 4iProto Server

Abdal 4iProto Server совместим со всеми стандартными клиентами протокола **SSHv2**, поддерживающими динамический SOCKS5-прокси (`Dynamic Port Forwarding`), а также со специализированными мобильными клиентами для обхода блокировок.

---

## 1. Базовые параметры подключения

Для настройки любого клиента вам потребуются реквизиты, выданные администратором:

| Параметр | Значение / Пример | Описание |
| :--- | :--- | :--- |
| **Хост (IP / Домен)** | `141.98.166.10` *(ваш IP сервера)* | Внешний IP-адрес сервера |
| **Порт подключения** | `64235` (или `64236`, `64237`) | Любой из открытых портов сервера |
| **Логин (Username)** | `user1`, `mob_1` и т.д. | Учетная запись из `users.json` |
| **Пароль (Password)** | `********` | Пароль учетной записи |
| **Локальный SOCKS5-порт** | `1080` (или `10808`, `52905`) | Локальный порт на вашем устройстве |

> [!IMPORTANT]
> **Предотвращение утечек DNS (SOCKS5 vs SOCKS5h):**
> Всегда включайте опцию **«Proxy DNS»** (удаленное разрешение DNS на стороне сервера). В противном случае ваш браузер или приложение будет отправлять DNS-запросы вашему локальному провайдеру, что приводит к утечке посещаемых сайтов и блокировкам по DNS.

## 2. Подключение с Linux

### Вариант A. Стандартный OpenSSH в терминале (Рекомендуемый)
Встроенная утилита `ssh` создает локальный SOCKS5-прокси одной командой:

```bash
ssh -N -D 1080 -p 64235 user1@141.98.166.10
```

- `-N` — не открывать удаленную командную оболочку (только туннелирование).
- `-D 1080` — открыть динамический SOCKS5-порт на локальном адресе `127.0.0.1:1080`.
- `-p 64235` — порт подключения к серверу.

После ввода пароля туннель переходит в фоновое ожидание.

#### Проверка работоспособности:
Откройте соседний терминал и выполните запрос через прокси:
```bash
curl -x socks5h://127.0.0.1:1080 https://ifconfig.me
```
*Команда должна вывести внешний IP-адрес вашего VPN-сервера.*

### Вариант B. Автопереподключение через AutoSSH (для серверов и роутеров)
Для постоянного туннеля, устойчивого к обрывам связи:
```bash
sudo apt-get install -y autossh

autossh -M 0 -f -N -D 1080 \
  -o "ServerAliveInterval 15" \
  -o "ServerAliveCountMax 3" \
  -o "ExitOnForwardFailure yes" \
  -p 64235 user1@141.98.166.10
```

## 3. Подключение с Windows

### Вариант A. Windows Terminal / PowerShell (OpenSSH)
Начиная с Windows 10 утилита OpenSSH предустановлена в системе.
1. Откройте **PowerShell** или **CMD**.
2. Выполните команду:
   ```powershell
   ssh -N -D 1080 -p 64235 user1@141.98.166.10
   ```
3. Введите пароль. Локальный прокси начнет слушать на `127.0.0.1:1080`.

### Вариант B. Через PuTTY
1. Запустите **PuTTY**.
2. В разделе **Session**:
   - **Host Name:** введите IP вашего сервера (например, `141.98.166.10`).
   - **Port:** `64235`.
   - **Connection type:** `SSH`.
3. В левом дереве перейдите: **Connection → SSH → Tunnels**:
   - В поле **Source port** укажите: `1080`.
   - В переключателе **Destination** выберите: `Dynamic`.
   - Нажмите кнопку **Add** (в списке появится строка `D1080`).
4. Вернитесь в раздел **Session**, введите имя в поле *Saved Sessions* и нажмите **Save**.
5. Нажмите **Open**, введите логин и пароль.

### Вариант C. Bitvise SSH Client
1. Скачайте [Bitvise SSH Client](https://www.bitvise.com/ssh-client-download).
2. На вкладке **Login**: укажите Host, Port, Username, Initial method: `password`.
3. На вкладке **Services**:
   - Поставьте галочку **SOCKS / HTTP Proxy Forwarding**.
   - **Listen Interface:** `127.0.0.1`.
   - **Listen Port:** `1080`.
4. Нажмите **Log in**. Клиент автоматически поддерживает связь и восстанавливает соединение при разрывах.

## 4. Подключение с Android

### Вариант A. NekoBox / v2rayNG
1. Установите **NekoBox for Android** (из GitHub или F-Droid) или **v2rayNG**.
2. Создайте новый профиль:
   - **Тип:** `SSH` или `SOCKS5` (при использовании локального SSH-демона).
   - Для типа SSH укажите:
     - Адрес сервера и порт: `141.98.166.10:64235`.
     - Имя пользователя и пароль.
3. Включите переключатель туннеля VPN — весь трафик устройства пойдет через сервер.

### Вариант B. HTTP Custom / NetMod Syna
1. Установите **HTTP Custom** из Google Play.
2. В главном окне перейдите в настройки SSH (иконка замка/ключа).
3. Заполните:
   - **SSH IP / Host:** `141.98.166.10`
   - **SSH Port:** `64235`
   - **Username:** `mob_1`
   - **Password:** `********`
4. Вернитесь на главный экран и нажмите **Connect**. Приложение создаст виртуальный VPN-интерфейс на Android.

## 5. Подключение с iOS (iPhone / iPad)

### Вариант A. Shadowrocket
1. Откройте **Shadowrocket** и нажмите **+** (добавить конфигурацию).
2. Выберите тип протокола **SSH** (или **SOCKS5**).
3. Заполните поля:
   - **Host:** `141.98.166.10`
   - **Port:** `64235`
   - **User:** `user1`
   - **Password:** ваш пароль
4. Сохраните и активируйте туннель.

### Вариант B. Streisand / Wings
1. Установите **Streisand** из App Store.
2. Добавьте узел типа **SSH**.
3. Укажите хост, порт, авторизационные данные и активируйте переключатель подключения.

## 6. Настройка браузеров для работы с SOCKS5

После запуска SOCKS5-прокси на `127.0.0.1:1080`:

### Mozilla Firefox
1. Откройте **Настройки → Настройки сети** (в самом низу страницы) → кнопка **Настроить...**.
2. Выберите **Ручная настройка прокси**.
3. В поле **Узел SOCKS:** введите `127.0.0.1`, **Порт:** `1080`.
4. Выберите переключатель **SOCKS v5**.
5. Обязательно отметьте галочку: **«Отправлять DNS-запросы через прокси SOCKS v5»**.
6. Нажмите **ОК**.

### Google Chrome / Brave / Edge (через расширение)
Рекомендуется использовать расширение **SwitchyOmega** или **Proxy SwitchyOmega**:
1. Создайте профиль типа `SOCKS5`.
2. Сервер: `127.0.0.1`, Порт: `1080`.
3. Примените изменения.
