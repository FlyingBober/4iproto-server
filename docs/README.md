# Документация Abdal 4iProto Server

Добро пожаловать в официальную техническую документацию **Abdal 4iProto Server** — высокопроизводительного многопоточного сервера безопасных туннелей на базе SSH, SOCKS5 и DNSTT, разработанного на языке Go.

Документация организована по международной методологии **[Diátaxis](https://diataxis.fr/)**, разделяющей материалы по практическим потребностям администратора: от быстрого старта до детального архитектурного справочника.

## 🔑 Ключевые возможности сервера

- **Мультипортовое прослушивание:** Одновременная работа на нескольких TCP-портах (например, `64235, 64236, 64237`).
- **Поддержка UDP и TCP туннелирования:** Реализация каналов SSH `direct-tcpip` и `direct-udpip` (для VoIP, игр, DNS).
- **Обход жестких сетевых блокировок (DNSTT over DNS):** Туннелирование трафика через DNS-запросы к порту 53 в сетях с белыми списками.
- **Управление сессиями и вытеснение (Session Eviction):** Автоматическое завершение старых зависших сессий при исчерпании лимита `max_sessions` (критично для мобильных сетей при переключении Wi-Fi ↔ LTE).
- **Гранулированное управление доступом:**
  - Ролевая модель: `admin` (доступ к shell) и `user` (только туннелирование).
  - Персональные ограничения скорости (`max_speed_kbps`).
  - Персональные квоты трафика (`max_total_mb`).
  - Фильтрация доменов и IP с поддержкой масок (`*.domain.com`, `192.168.1.*`).
- **Отказоустойчивость и безопасность:**
  - Атомарное сохранение статистики трафика (`atomicWriteJSON`).
  - Встроенный Guard против брутфорса (блокировка после `max_auth_attempts`).
  - Graceful Shutdown по сигналам `SIGINT`/`SIGTERM`.
  - Хранение активных сессий во встроенной базе данных BoltDB.

## 📂 Структура файлов проекта

```
/usr/local/abdal-4iproto-server/           # Рекомендуемый рабочий каталог сервера
├── abdal_4iproto_server_linux_amd64       # Исполняемый бинарный файл
├── server_config.json                     # Конфигурация сервера и портов
├── users.json                             # База пользователей и политик доступа
├── blocked_ips.json                       # Глобальный черный список IP
├── id_ed25519                             # Приватный SSH Host Key сервера
├── id_ed25519.pub                         # Публичный SSH Host Key сервера
├── data/
│   └── sessions.db                        # База активных сессий (BoltDB)
├── users_traffic/                         # Персональные файлы учета трафика
│   └── traffic_<username>.json
└── users_log/                             # Детальные логи обращений пользователей
    └── <username>.log
```
